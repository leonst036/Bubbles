# Bubbles

Bubbles is a cute app on your smartpone that can control you PC and make you happy. It's a cute buddy for you.

## How to install

1. Clone the repository
2. Install dependencies in backend
3. Set var GEMINI_API_KEY in backend/.env
4. Run the backend (main.py)
5. Install android app (You'll need to build it yourself and change the backend URL in HeartbeatClient.kt)
